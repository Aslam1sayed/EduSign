# EduSign — مساعد تعليمي للطلاب الصم

يحوّل كلام المعلم إلى نص فوري مع رسوم توضيحية متحركة للمصطلحات، بالعربية والإنجليزية.

## الملفات
- `index.html` — الموقع كاملًا (واجهة + منطق).
- `manifest.webmanifest` — بيانات التطبيق القابل للتثبيت.
- `sw.js` — Service Worker للعمل دون إنترنت.
- `icons/` — أيقونتا التطبيق (192 و512).

## التشغيل
افتح الموقع عبر HTTPS (مثل GitHub Pages) أو `localhost`. فتح الملف مباشرة من الجهاز لا يفعّل الميكروفون ولا العمل دون إنترنت.

## ملاحظات
- تحويل الصوت إلى نص يستخدم محرك المتصفح (Chrome / Edge) ويحتاج إنترنت. بقية الميزات تعمل دون اتصال.
- عند تعديل الملفات غيّر رقم النسخة في أول `sw.js` (مثل `edusign-v8`) ليحمّل المتصفح التحديث.
